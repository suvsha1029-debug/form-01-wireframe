# Form 01 - Visual Playground

Interactive celestial wireframe playground, migrated from ChatGPT Sites to GitHub Pages.
Drag to rotate the form or use the toss control. The existing artwork and behavior
are retained; the application now builds as a static React site.

Live: https://suvsha1029-debug.github.io/form-01-wireframe/

Requires Node.js 22.13 or newer. Run `npm ci`, then `npm run dev` or `npm run build`.
To publish an update, copy the contents of `dist` into `docs` and commit/push.
GitHub Pages serves the main branch's `/docs` folder.
